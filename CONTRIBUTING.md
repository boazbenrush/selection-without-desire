# Contributing

Corrections, replication attempts, falsification results, and extensions are welcome.

Please keep the following distinctions explicit in any contribution:

- analytical result vs numerical verification
- synthetic evidence vs external empirical evidence
- agent-level deliberative adaptation vs lineage-level ecological selection

For issues or proposed changes, cite the canonical v1.0 DOI when referring to the published framework:

https://doi.org/10.5281/zenodo.22730599

Substantive extensions should state clearly whether they preserve or alter the GPIN definition, the neutral-policy setup, the hazard mapping, or the D/E mechanism-discrimination design.
