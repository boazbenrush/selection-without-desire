# Data

This repository includes compact reported summary outputs that are easy to inspect directly on GitHub:

- `factorial_2x2_summary.csv` — 2×2 mechanism-discrimination cell summaries
- `factorial_regression.csv` — robust regression coefficients for D, E, and D×E
- `gpin_holdout_metrics.csv` — train/holdout classification metrics for the GPIN boundary
- `directed_design_governance_stress.csv` — stress-test summary over directed successor design and governance penalty

The full canonical synthetic raw outputs, including the 800-run factorial data, 300-environment GPIN holdout data, and resource-elasticity grid, are archived in the v1.0 publication package associated with the canonical Zenodo record:

https://doi.org/10.5281/zenodo.22730599

This separation keeps the GitHub repository lightweight while preserving the DOI-backed raw release as the authoritative snapshot.
