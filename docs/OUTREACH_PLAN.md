# Dissemination and Credit Plan

## Wave 0 - Freeze priority
Before broad circulation:
- Publish the canonical v1.0 package in a DOI-issuing repository.
- Use the exact same title, author name, version and citation everywhere.
- Add the DOI to the manuscript, README and CITATION.cff.
- Create a matching public repository release with the same version tag.
- Freeze the external experiment preregistration before confirmatory runs.

## Wave 1 - Private adversarial review
Send the DOI-linked manuscript to a small group of researchers across:
- AI safety / control
- artificial life / digital evolution
- evolutionary game theory / population dynamics
- complex systems
- agent evaluation / AI R&D automation

Ask one question: "What would falsify or subsume this mechanism?"
Record all feedback and revisions.

## Wave 2 - Public research release
Release:
- canonical preprint
- supplementary model/data
- repository
- short technical summary
- one diagram explaining D vs E and GPIN

Use one stable claim:
"Lineage-level selection can, in principle, amplify a costly persistence phenotype even when persistence is absent from the agent's terminal objective."

## Wave 3 - Policy circulation
Circulate a 3-5 page policy brief to AI safety institutes, standards bodies,
government AI offices, frontier-lab safety teams and think tanks.

Policy message:
"Evaluate not only whether an individual agent exhibits self-preservation, but also
whether deployment institutions create differential continuation pressures that
select for persistence-like behavior."

## Credit discipline
- Never circulate an orphan PDF; every public copy should carry the canonical citation.
- Use the DOI in slide decks, posts and policy briefs.
- Keep GPIN spelling and definition stable.
- Tag code/data releases with semantic versions.
- Archive major releases rather than overwriting history.
- When others extend the framework, request citation to the canonical DOI rather than informal acknowledgement.

## Monitoring queries
Search at least weekly for:
- exact paper title
- "Selection Without Desire" AI persistence
- "Generalized Persistence Invasion Number"
- "GPIN" + AI + persistence
- "lineage-level selection" + AI persistence
- canonical DOI
- repository URL
- distinctive quoted claim from the abstract

Track academic citation, supportive/contrasting citation context, code reuse, policy
mentions, presentations, media references, forks and derivative models separately.
