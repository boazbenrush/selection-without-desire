# Credit and Citation

The stable credit anchor for this project is the canonical Zenodo DOI:

**10.5281/zenodo.22730599**

Preferred citation:

Benrush, B. (2026). *Selection Without Desire: Eco-Evolutionary Emergence of Persistence in Resource-Constrained Self-Designing AI Populations* (Version 1.0.0). Zenodo. https://doi.org/10.5281/zenodo.22730599

## For derivatives and extensions

When reusing or extending the framework, please distinguish between:

- reuse of the GPIN formalism;
- reuse of the D/E mechanism-discrimination design;
- reuse of the synthetic model or data;
- independent empirical tests of the population-selection hypothesis.

Where any of these are materially used, cite the DOI-backed v1.0 research record. GitHub repository references are useful for code provenance, but the DOI should remain the primary scholarly citation.

## Versioning

Use `v1.0.0` when referring to this public release. Substantive later revisions should receive a new version so priority and the evolution of the framework remain auditable.
